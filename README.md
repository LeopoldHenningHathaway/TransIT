# tl;dr TransIT ist ein kleines Data Science/Analytics Projekt, um primär Recruitern und verantwortlichen zu zeigen, dass ich nicht ungeeignet bin!

Inhaltlicher Scope ist u.a. durch meine Tätigkeit bei der PTV Transport Consult und meiner Heimat (Weimar) entstanden
Ziel: die Aus- und Bewertung des ÖPNV in Weimar bzw. größer Gedacht den VMT-Verbund und in einem realen Miniprojekt mein eigenständiges Können zu zeigen

# (voraussichtlicher) Techstack
1. Python und (Postgre)SQL zur weitestgehenden ETL-Pipeline
2. Git(Hub) zur Versionierung
3. PowerBI zur Visualisierung
4. Docker
5. Irgendwas mit Cloud (voraussichtlich MS Azure) außer es ist mir zu teuer
